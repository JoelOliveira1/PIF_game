# PIF_game

Um jogo de survival horror 2D em pixel art com visão de cima, ambientado em um manicômio. Após sobreviver trancado na solitária, o jogador precisa explorar o local, encontrar maneiras de escapar enquanto foge de um psicopata que o persegue. Com uma lanterna de alcance limitado e o tempo correndo, cada decisão pode ser crucial.
